One thing to install by hand

          
Sealbox needs GnuPG, and this Mac has no package manager it can use.
            Copy the line below, paste it into Terminal and press Enter. It installs Homebrew,
            which then installs GnuPG.

          
        

        

          
          

            
Paste this into Terminal

            
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

          

        

        

          

          

            
This command is not ours

            
It is the official Homebrew installer, from brew.sh. Sealbox never runs it for you.

Enable Seed mode

          
Seed mode lets you restore your key after a Ledger or OpenPGP update.

          
          
        

        

          
1Quit Ledger Live

          
2Open OpenPGP on your Ledger

          
3Open Settings → Seed mode

          
4Turn it On
